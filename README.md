# Student Performance Analyzer

## Overview

A beginner-friendly Python project that analyzes student performance using a dataset.

## Technologies Used

* Python
* Pandas

## Dataset

`Student_Dataset.csv` contains student information and academic grades.

## Features

* Count total students
* Calculate average marks in different subjects
* Find the highest and lowest grades
* Calculate students' average grades

## Project Files

* `StudentPerformance.py` — Python source code
* `Student_Dataset.csv` — Dataset used by the project
* `README.md` — Project documentation

## How to Run

1. Install Python.

2. Install Pandas:

   `pip install pandas`

3. Keep the Python file and CSV dataset in the same project folder.

4. Open a terminal inside the project folder and run:

   `python StudentPerformance.py`
