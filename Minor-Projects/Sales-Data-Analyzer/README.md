# Sales Data Analyzer

## About the Project

Sales Data Analyzer is a beginner-level Data Science mini-project built using Python, NumPy, and Pandas. It analyzes sales data to calculate revenue, identify high-performing orders, and explore customer information.

## Technologies Used

* Python
* NumPy
* Pandas

## Project Files

* `SalesAnalysis.py` — Python program for sales analysis.
* `sales_data.csv` — Dataset used for analysis.
* `README.md` — Project documentation.

## Features

1. Calculate total revenue after discounts.
2. Calculate average order value.
3. Find the highest-revenue order.
4. Find the lowest-revenue order.
5. Calculate total quantity sold.
6. Calculate average discount.
7. Calculate average customer age.
8. Analyze the correlation between ratings and revenue.
9. Detect unusual orders using the IQR method.
10. Normalize revenue using Min-Max normalization.
11. Display the top 5 orders by revenue.
12. Categorize customers by age.

## How to Run

### 1. Install the required libraries

```bash
pip install numpy pandas
```

### 2. Run the program

Open a terminal in the project folder and execute:

```bash
python SalesAnalysis.py
```

### 3. Select an option

Follow the menu displayed in the terminal to perform different sales analyses.
