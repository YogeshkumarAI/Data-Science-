# Minor Data Science Projects

Welcome to the **Minor Projects** section of my Data Science learning journey. These beginner-friendly projects use Python and data analysis libraries to practice working with real-world-style datasets, performing calculations, and extracting useful insights.

## Projects

### 1. Student Performance Analyzer

Analyze student records and academic grades to explore student performance.

**Technologies:** Python, Pandas, NumPy

**Key features:**
- Count the total number of students.
- Calculate average grades.
- Identify high and low scores.
- Analyze student performance using dataset columns.

**Project files:** [Open Student Performance Analyzer](./Student-Performance-Analyzer/)

- `StudentPerformance.py` — Python analysis program
- `Student_Dataset.csv` — Dataset
- `README.md` — Project documentation

### 2. Weather Analyzer

Analyze daily weather observations, including temperature, humidity, and rainfall.

**Technologies:** Python, NumPy, Pandas

**Key features:**
- Calculate average, maximum, and minimum temperature.
- Calculate average humidity and total rainfall.
- Identify the hottest, coldest, and rainiest days.
- Calculate temperature standard deviation.
- Explore temperature-humidity and temperature-rainfall correlations.
- Calculate changes between consecutive temperature observations.

**Project files:** [Open Weather Analyzer](./Weather-Analyzer/)

- `WeatherAnalyzer.py` — Python analysis program
- `weather_data.csv` — Weather dataset
- `README.md` — Project documentation

## How to Run a Project

1. Open the project folder you want to run.
2. Make sure Python is installed.
3. Install the libraries required by that project. For these projects, you can use:

   ```bash
   pip install numpy pandas
   ```

4. Run the Python file from its project folder. For example, for Weather Analyzer:

   ```bash
   python WeatherAnalyzer.py
   ```

   For Student Performance Analyzer:

   ```bash
   python StudentPerformance.py
   ```
