# Weather Analyzer

## About the Project

Weather Analyzer is a beginner-level Data Science mini-project built using Python, NumPy, and Pandas. It analyzes weather data to understand temperature, humidity, rainfall, and daily temperature changes.

## Technologies Used

* Python
* NumPy
* Pandas

## Project Files

* `WeatherAnalysis.py` — Python program for weather analysis.
* `weather_data.csv` — Dataset used for analysis.
* `README.md` — Project documentation.

## Features

1. Calculate average temperature.
2. Find maximum temperature.
3. Find minimum temperature.
4. Calculate average humidity.
5. Calculate total rainfall.
6. Find the hottest day.
7. Find the coldest day.
8. Find the rainiest day.
9. Calculate temperature standard deviation.
10. Calculate temperature-humidity correlation.
11. Calculate temperature-rainfall correlation.
12. Analyze changes in temperature between consecutive observations.

## Installation

Install the required libraries:

```bash
pip install numpy pandas
```

## How to Run

Open the terminal inside the project folder and execute:

```bash
python WeatherAnalysis.py
```

Follow the menu to select the weather analysis you want to perform.

## Learning Objectives

* Practice NumPy operations on arrays.
* Load CSV datasets using Pandas.
* Calculate statistical measures.
* Understand correlation and standard deviation.
* Analyze changes in weather data.
* Learn to organize a Data Science project on GitHub.
